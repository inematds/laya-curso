1

Abra a interface local

O que é

O comando serve inicia um servidor em 127.0.0.1, porta 8765 por padrão. Abra o endereço no navegador da mesma máquina. O formulário aceita assunto opcional e mensagem; botões de exemplo preenchem casos de cobrança, suporte e vendas sem disparar uma análise automaticamente.

Por que aprender

O guia publicado no GitHub Pages é documentação estática; a interface de inferência roda na máquina que executa Python. Não confunda um link público do curso com um servidor de modelos. A primeira análise pode carregar os pesos e levar mais tempo.

Exemplo aplicado

python3 -m practical --device cuda serve --port 8765; abra http://127.0.0.1:8765.

Leia o resultado como recomendação

O que é

A tela mostra departamento, confiança SDK, urgência, ameaça de cancelamento e pedido de reembolso. O JSON completo preserva distribuições e metadados para inspeção. Um campo numérico só é útil quando você conhece a pergunta que o gerou e a escala usada.

Por que aprender

Comece pelo texto original, confira o setor sugerido e procure sinais contraditórios. Uma solicitação pode conter reembolso sem cancelamento; insatisfação não implica urgência crítica. A interface mantém revisão humana e informa que a calibração não foi validada no domínio do cliente.

Exemplo aplicado

Ticket: obrigado, o estorno chegou. A presença da palavra estorno não deve ser interpretada automaticamente como um novo pedido.

A política fica fora do modelo

O que é

review_policy recebe respostas validadas e constrói o encaminhamento. A implementação retorna human_review em todos os casos e automated_action_executed false. O limiar de confiança acrescenta uma razão de revisão; não habilita ação automática. Essa fronteira é uma decisão explícita do produto.

Por que aprender

Separar política e inferência permite modificar regras de operação sem reescrever o encoder. Também evita tratar act_probability, um campo aprendido do upstream, como permissão real para usar ferramentas, pagar valores ou apagar registros.

Exemplo aplicado

Modelo: refund_requested 0,95. Política: atendente deve conferir cobrança, identidade e regra de estorno em seus sistemas.

Dica prática

Defina ações permitidas, valide qualidade com dados próprios, estabeleça limites e auditoria, teste falhas e aprove a política. Um limiar isolado não substitui esse trabalho.

Comando / esquema de referência

python3 -m practical serve --port 8765
# Em outro terminal:
curl -X POST http://127.0.0.1:8765/api/triage \
  -H "Content-Type: application/json" \
  -d '{"message":"Fui cobrado duas vezes."}'

4

Use a API com contrato pequeno

O que é

POST /api/triage recebe somente message e subject. A validação rejeita campos extras, mensagem vazia e tamanho excessivo. GET /api/health informa se o servidor responde e se o modelo já foi carregado. O health não executa inferência nem garante qualidade preditiva.

Por que aprender

Um consumidor deve checar o status HTTP antes de usar answers. A resposta 422 indica um problema de entrada, como limite de tokens; 503 indica indisponibilidade do modelo. Tratar ambas como setor other esconderia falhas e poluiria suas métricas.

Exemplo aplicado

Envie JSON com message; processe answers somente após HTTP 200. Registre o tipo de erro separado do rótulo previsto.

✓ Aplicar com critério

A checagem deve ser rápida e sem efeito caro. Ela distingue serviço vivo de modelo carregado; a inferência real continua sendo o teste do caminho completo.

Dados e exportação

O que é

A aplicação não grava automaticamente o texto dos tickets. O usuário pode baixar um resultado JSON, que contém previsões e metadados de execução. Os exemplos embarcados são sintéticos. Para avaliação própria, minimize os dados pessoais e defina onde os arquivos ficarão armazenados.

Por que aprender

Rodar localmente evita enviar o ticket a uma API de inferência externa, mas os pesos precisam ser obtidos do Hub inicialmente. Logs do servidor e arquivos exportados também fazem parte da operação; revise suas configurações antes de usar dados reais.

Exemplo aplicado

Substitua nome, e-mail e número completo de documento por identificadores internos quando não forem necessários à classificação.

Dica prática

Não. A máquina, os logs, os backups e as pessoas com acesso continuam relevantes. Use apenas os dados necessários e as regras da sua organização.

6

Laboratório de ponta a ponta

O que é

Execute o servidor, carregue um exemplo, analise, inspecione o JSON e baixe o resultado. Em seguida, altere uma frase de forma significativa: de vou cancelar para não vou cancelar. Compare o sinal de ameaça e registre se o modelo acompanhou a negação.

Por que aprender

Esse teste revela comportamento real sem exigir um benchmark grande. Não altere o rótulo esperado depois de ver a resposta apenas para contar um acerto. Separe a revisão do esquema da avaliação: se mudar a pergunta, inicie uma nova versão do experimento.

Exemplo aplicado

Crie pares mínimos: quero reembolso versus não quero reembolso; serviço parado versus serviço voltou.

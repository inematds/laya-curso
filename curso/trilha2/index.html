MÓDULO 2.1

Instalação e primeira inferência

Execute pesos reais na sua máquina.

O que é

O clone contém o SDK e a aplicação prática; os pesos são baixados separadamente do Hugging Face.

Por que aprender

Clonar o Git não baixa automaticamente o checkpoint.

Conceitos-chave

Clone

código versionado

Venv

isolamento Python

Checkpoint

pesos treinados

Cache

arquivos já baixados

O que é

A aplicação usa CPU por padrão, permitindo experimentar sem uma GPU compatível.

Por que aprender

Não copie os 33 ms publicados para descrever a sua máquina.

Conceitos-chave

CPU

execução geral

CUDA

aceleração NVIDIA

Fallback

dispositivo alternativo

Ambiente

versões reais

O que é

A adaptação pré-carrega apenas multilingual, usando o subdiretório correspondente do repositório de modelos.

Por que aprender

Preload de todos os modelos pode ser adequado para tráfego variado, mas aumenta a memória residente.

Conceitos-chave

Preload

carga antecipada

Residência

modelo em memória

Subfolder

variante do bundle

Memória

pesos e intermediários

O que é

O comando triage recebe mensagem e assunto opcional, executa as quatro perguntas e imprime JSON.

Por que aprender

O comando deve encerrar com erro quando a entrada é inválida ou o modelo falha.

Conceitos-chave

CLI

interface de comando

Exit code

resultado do processo

Answers

previsões

Policy

decisão operacional

O que é

O fork parte do commit upstream registrado na documentação.

Por que aprender

Se um resultado mudar, compare primeiro essas identidades.

Conceitos-chave

Revisão

commit exato

Snapshot

versão dos pesos

Dependência

biblioteca

Reprodução

repetir condições

O que é

Comece identificando a camada da falha: importação, download, carregamento, tokenização ou forward pass.

Por que aprender

O laboratório expõe falhas na API e não inventa uma classificação substituta.

Conceitos-chave

MÓDULO 2.2

Router, contexto e processamento

Evite encaminhar uma entrada ao modelo errado.

O que é

Router.route pode selecionar um checkpoint sem executar a rede neural.

Por que aprender

O código atual deve prevalecer sobre diagramas simplificados.

Conceitos-chave

Roteamento

seleção prévia

Override

indicação explícita

Script

sistema de escrita

Workflow

esquema especializado

O que é

Português usa alfabeto latino, como inglês, e mensagens muito curtas oferecem pouca evidência para detecção automática.

Por que aprender

Uma regra simples baseada em informação confiável do produto pode superar uma heurística de idioma.

Conceitos-chave

Idioma conhecido

metadado confiável

Texto curto

pouca evidência

Heurística

aproximação

Contrato linguístico

escopo

O que é

O prompt interno reserva espaço para pergunta e opções; o restante acomoda o estado.

Por que aprender

O SDK pode truncar o estado.

Conceitos-chave

Token

unidade do tokenizer

Head

pergunta e opções

Estado

conteúdo do ticket

Truncamento

perda de entrada

O que é

Cada alternativa precisa ter marcadores e texto suficiente para permanecer distinguível.

Por que aprender

Uma alternativa é hierarquia: primeiro escolha uma família e depois uma subcategoria.

Conceitos-chave

Cardinalidade

número de classes

Hierarquia

Propagação

Descrição

O que é

O Router padrão mantém poucos modelos quentes e pode descartar o menos recente.

Por que aprender

Medições devem distinguir o caminho quente da primeira carga e das trocas.

Conceitos-chave

Por que aprender

Conceitos-chave

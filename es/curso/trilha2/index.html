MÓDULO 2.1

Instalación e primera inferencia

Ejecuta pesos reales en tu máquina.

Qué es

El clone incluye el SDK y la aplicación práctica; los pesos se descargan por separado desde Hugging Face.

Por qué aprender

Clonar el Git no descarga automáticamente el checkpoint.

La aplicación usa CPU de forma predeterminada, lo que te permite experimentar sin una GPU compatible.

Por qué aprender

MÓDULO 2.2

Router, contexto y procesamiento

Evita encaminar una entrada al modelo equivocado.

Qué es

Router.route puede seleccionar un checkpoint sin ejecutar la red neuronal.

Por qué aprender

El código actual debe prevalecer sobre diagramas simplificados.

Conceptos clave

Enrutamiento

selección previa

Override

indicación explícita

Script

sistema de escritura

Workflow

esquema especializado

Qué es

Portugués usa alfabeto latino, como inglés, y los mensajes muy cortos ofrecen poca evidencia para la detección automática.

Por qué aprender

Una regla simple basada en información confiable del producto puede superar una heurística de idioma.

Conceptos clave

Idioma conocido

metadato confiable

Texto corto

poca evidencia

Heurística

Contrato lingüístico

Qué es

El prompt interno reserva espacio para la pregunta y las opciones; el resto acomoda el estado.

Por qué aprender

El SDK puede truncar el estado.

Conceptos clave

Token

Encabezado

Estado

Truncamiento

Qué es

Cada alternativa debe tener viñetas y texto suficiente para seguir siendo distinguible.

Por qué aprender

Una alternativa es jerarquía: primero elige una familia y luego una subcategoría.
